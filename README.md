# PatientOS - Enterprise Healthcare Management System

PatientOS is a clinical management platform designed for hospital administration, patient record tracking, emergency triage, bed resource management, billing, and security compliance.

## Features
- **Dashboard**: Overview of hospital metrics, daily appointments, and recent patient activity.
- **Bed Resource Management**: Visual ward/ICU/room floorplan view, bed allocation, and patient status.
- **Emergency Triage Desk**: ESI triage queue (Level 1 Resuscitation to Level 5) with Code Blue trigger system.
- **Settings & Preferences**: Complete settings panel featuring Dark Mode switching, Profile management, Privacy & 2FA controls, Language selection, and Help Center.
- **Security & Compliance Audit Logs**: Real-time event tracking, severity filtering, and HIPAA compliance export.
- **Billing & Invoices**: Invoice management, payment status, dynamic totals, and checkout flow.
